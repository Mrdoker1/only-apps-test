Содержание

    Robinzone Design Spec v1.4 «Charged»

    Самодостаточная спецификация для внешней команды. Все значения — абсолютные. Стек-агностично (примеры на CSS + Tailwind-совместимых классах). Тема одна — тёмная, светлой нет.

    1. Цвет

    1.1 Базовые токены (HSL, как в CSS-переменных)

    Токен HSL HEX Применение

    card 232 16% 14% #1E2029 карточки, панели
    popover 232 18% 12% #191B24 выпадающие поверхности

    1.3 Текстовая шкала

    --t0 #ffffff (акцентный заголовок) → --t1 #e2e6f4 (основной) → --t2 #9098b8 (вторичный) → --t3 #5c6280 (третичный, подписи) → --t4 #363d56 (disabled/декор).

    1.4 Градиент бренда

    Один и только один:

    background: linear-gradient(135deg, #C8FF00 0%, #00C2FF 100%);

    Для текста — тот же градиент + background-clip: text; -webkit-text-fill-color: transparent. Градиент героя: linear-gradient(180deg, #191B24 0%, #13141B 70%).

    1.5 Правила цвета

    • Volt (#C8FF00) — только для одного главного CTA на экран, фокус-кольца и активных состояний. Не использовать как фон больших областей.
    • Текст на Volt всегда #0a1100. Белый текст на Volt запрещён (контраст < 3:1).
    • Границы: базовая rgba(255,255,255,0.10), «тихая» rgba(255,255,255,0.05), hover rgba(255,255,255,0.15).
    • Хардкод произвольных hex вне этой таблицы запрещён.

    2. Типографика

    Шрифты (Google Fonts):

    Plus Jakarta Sans: 200,300,400,500,600,700,800 + italic 400,500
JetBrains Mono: 300,400,500

    • JetBrains Mono — только для настоящего mono-контента: код, ID/slug, табличные числа, технические/админские экраны, мета-подписи.
    Роль Размер Вес Line-height Letter-spacing
    body 15px 400 1.55 0
    small / caption 13px 400–500 1.5 0
    mono-meta (бейдж-подписи) 11px 500 1.4 0.08em, uppercase
    h1 clamp(32px, 6vw, 60px) 800 1.05 −0.025em
    h2 clamp(24px, 4vw, 40px) 700 1.05 −0.025em

    3. Сетка, отступы, лейаут

    3.1 Шаг сетки

    Базовый шаг 4px. Разрешённые отступы: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96px. Промежуточных значений не изобретаем.

    3.2 Контейнер страницы (full-bleed)

    Приложение full-bleed: контент растянут на всю ширину, ограничение делают только горизонтальные паддинги.

    .page-shell {
  width: 100%;
  padding-left:  max(16px, env(safe-area-inset-left));
  padding-right: max(16px, env(safe-area-inset-right));
}
@media (min-width: 640px)  { .page-shell { padding-inline: 24px; } }
@media (min-width: 1024px) { .page-shell { padding-inline: 32px; } }
@media (min-width: 1280px) { .page-shell { padding-inline: 40px; } }
@media (min-width: 1536px) { .page-shell { padding-inline: 48px; } }

    Запрещено: margin-inline: auto + max-width на корне страницы, любые «bootstrap-подобные» центрирующие контейнеры. Исключение: промо-секции лендинга оборачиваются в inset-карточку с margin-inline: 12px (≥640px — 16px), а с 1024px — max-width: 1240px; margin-inline: auto.

    3.3 Брейкпоинты

    sm 640px, md 768px, lg 1024px, xl 1280px, 2xl 1536px. 768px — граница «мобайл/десктоп»: ниже — нижняя навигация и Sheet-паттерны, выше — верхняя навигация и Dialog.

    3.4 Вертикальные размеры

    Элемент Значение
    Высота шапки 64px (+ env(safe-area-inset-top))
    Мобильная нижняя навигация 60px (+ env(safe-area-inset-bottom))
    Отступ секции (моб / десктоп) 48px / 80px по вертикали
    Внутренний паддинг карточки 24px (компактная — 16px)
    Зазор в сетке карточек 16px моб, 24px десктоп

    Высоты экрана считаем через 100dvh, никогда 100vh:

    min-height: min(100dvh, var(--vvh, 100dvh));

    overflow: hidden на body запрещён (ломает скролл iOS) — только overflow-x: clip.

    4. Радиусы, тени, движение

    • Базовый радиус: 10px (--radius: 0.625rem). Производные: sm 6px, md 8px, lg 10px, xl 12px, 2xl 16px.
    • Кнопки, чипы, бейджи, пилюли — всегда border-radius: 9999px. Прямоугольных кнопок нет.
    • Панели/карточки: 12–16px. Триггер селекта: 14px. Поповер-контент селекта: 26px.
    • Теней в классическом смысле нет — вместо «серого блюра» используется свечение:
    --glow-volt:   0 0 20px rgba(200,255,0,0.25), 0 0 60px rgba(200,255,0,0.08);
--glow-plasma: 0 0 20px rgba(159,110,255,0.22), 0 0 60px rgba(159,110,255,0.08);
--glow-brand:  0 0 32px rgba(200,255,0,0.20), 0 0 80px rgba(200,255,0,0.08);

    Внутренний хайлайт кнопки: inset 0 1px 0 rgba(255,255,255,0.12).

    • Переходы: 150–200 ms, easing ease-out; анимируем только background-color, border-color, color, opacity, transform, filter. Layout-свойства не анимируем.
    • Hover CTA: translateY(-1px) + brightness(1.10). Active: scale(0.97) (или translateY(0.5px) для утилитарных кнопок).
    • Появление контента: fade-up — opacity 0→1, translateY(16px→0), 500 ms, cubic-bezier(0.16, 1, 0.3, 1). Переход страницы: тот же кейфрейм 300 ms.
    • Пульс свечения (для «идёт генерация»): 2.5–3 s ease-in-out infinite, от 20px/0.25 до 32px/0.42.
    • Все анимации обязаны отключаться при prefers-reduced-motion: reduce.

    5. Слои (z-index)

    Слой z Что
    Контент 10 подложки, hover-контролы внутри карточек
    Локальный оверлей 20–30 sticky-заголовки таблиц, плавающие панели секции
    Sticky-шапка / сайдбар 40 навигация
    Портальные оверлеи 50 Dialog, Sheet, Select, Popover, Menu, Tooltip, Toast
    Coach-marks, бейджи режима 70–80 onboarding, индикаторы окружения
    Полноэкранные блокеры 100 welcome-оверлей, модалка авторизации, мобильная нижняя навигация

    Любой оверлей рендерится в портал в body, а не внутри секции — иначе overflow/transform предка обрежет его.

    6. Выпадающие списки и оверлеи — правила размещения

    6.1 Когда какой компонент

    Ситуация Компонент
    Выбор одного значения из фиксированного набора (2+ опций) Select (выпадающий список)
    Действия над объектом Dropdown menu по клику на иконку «…»
    Фильтры, сложный контент выбора, поиск внутри Popover
    Мультивыбор Popover со списком чекбоксов + чипы выбранного под триггером
    Подтверждение/форма (десктоп) Dialog по центру
    То же на ширине < 768px Sheet снизу
    Пояснение к иконке Tooltip

    Радио-группы — только когда опций ≤ 3 и нужно видеть все варианты одновременно (например, тариф). Во всех остальных случаях — выпадающий список. Нативный <select> не используется (кроме крайних случаев на мобиле).

    6.2 Позиционирование (одинаково для Select, Menu, Popover)

    • Стратегия — anchored popper, ширина списка ≥ ширины триггера (min-width: 8rem, для Select — min-width = ширина триггера).
    • Направление по умолчанию: вниз (side="bottom", align="start").
    • Автопереворот: если снизу до края вьюпорта меньше высоты списка — список открывается вверх. Никакой ручной логики «всегда сверху» — только авто-flip.
    • Список никогда не перекрывает свой триггер. Отступ от триггера: 4px (offset), для Select добавляется translateY(4px) вниз / -4px вверх.
    • Максимальная высота списка: 384px (24rem), дальше внутренний скролл со стрелками-скроллерами сверху/снизу.
    • Максимальная ширина: calc(100vw - 16px); на мобиле список прижимается к краям с полем 8px.
    • Выравнивание: start для полей формы, end для меню действий в правом верхнем углу.
    • Клик по фону, Esc, скролл контейнера (для меню) — закрывают список; фокус возвращается на триггер.

    6.3 Анимация открытия

    fade-in 0 → 1 + zoom-in 95% → 100%, 150 ms, плюс сдвиг на 8px со стороны, противоположной открытию (side=bottom → въезд сверху). Закрытие — зеркально, 100 ms.

    6.4 Внешний вид

    • Триггер Select: высота 40px, паддинг 12px, радиус 14px, фон rgba(30,32,41,0.75) + backdrop-filter: blur(20px), граница rgba(255,255,255,0.10), внутренний хайлайт inset 0 1px 0 rgba(235,238,249,0.05), справа шеврон 16px с opacity .5.
    • Контент: фон #191B24, граница rgba(255,255,255,0.10), радиус 26px (меню/поповеры — 8–12px), паддинг 4px.
    • Пункт: высота 36px, паддинг 8px 12px (при наличии чек-маркера — padding-left: 32px), радиус 6px, hover/focus — фон rgba(255,255,255,0.06), выбранный — Volt-галочка 16px слева, текст #e2e6f4.
    • Заголовок группы: 12px/600, #9098b8, паддинг 8px 12px. Разделитель: 1px #3A3C4A, вертикальные поля 4px.

    7. Компоненты — точные значения

    7.1 Кнопка

    Общее: display:inline-flex; align-items:center; justify-content:center; gap:8px; border-radius:9999px; font-size:14px; font-weight:600; transition:150ms; фокус — кольцо 2px #C8FF00 с offset 2px; disabled — opacity: .45, курсор по умолчанию.

    Размер Высота Паддинг Шрифт Иконка
    sm 36px 0 16px 13px 14px
    default 40px 0 20px 14px 16px
    lg 48px 0 28px 15px 16px
    icon 40×40px — — 16px
    icon-sm 32×32px — — 14px
    Вариант Фон Текст Граница Hover
    primary (CTA) #C8FF00 #0a1100 нет #D8FF44, translateY(-1px), свечение 28px
    sky #00C2FF #001a24 нет #33CEFF, translateY(-1px)
    secondary #2E303D #EBEEF9 rgba(255,255,255,0.10) фон #3A3C4A
    outline прозрачный #EBEEF9 rgba(255,255,255,0.15) фон rgba(255,255,255,0.05)
    ghost нет #9FA5BC нет фон rgba(255,255,255,0.05), текст #EBEEF9
    destructive #FF4D3D #FFFFFF нет brightness(1.1)

    Правило: один primary-CTA на экран. Остальное — secondary/outline/ghost.

    7.2 Поле ввода

    Высота 40px (textarea — min 96px), радиус 10–14px, фон #191B24, граница rgba(255,255,255,0.10), паддинг 0 12px, шрифт 14px (на мобиле 16px), placeholder #5c6280. Focus: граница прозрачная + кольцо 2px #C8FF00 с offset 2px. Ошибка: граница #FF4D3D, подпись 13px #FF4D3D под полем с отступом 6px. Лейбл: 13px/500 #9FA5BC, отступ снизу 6px.

    7.3 Карточка

    Радиус 12px, фон #1E2029, граница rgba(255,255,255,0.05) → hover rgba(255,255,255,0.10), overflow:hidden, transition 200ms. Паддинг блоков: header/content/footer — 24px (padding-top: 0 у content и footer). Заголовок 24px/600, описание 14px #9FA5BC.

    7.4 Диалог / Sheet

    • Оверлей: rgba(0,0,0,0.80), fade 200 ms, z-index: 50.
    • Dialog: по центру, ширина calc(100vw - 16px), max-width: 512px, паддинг 24px, радиус 12px (на < 640px — во всю ширину с полями 8px), gap между блоками 16px. Анимация: fade + zoom 95→100% + сдвиг 2% сверху, 200 ms.
    • Sheet: со стороны экрана, паддинг 24px, ширина боковой панели max-width: 400px, нижний sheet — высота до 88svh, вход 500 ms / выход 300 ms.
    • Заголовок 18px/600, описание 14px #9FA5BC. Кнопка закрытия — icon-sm в правом верхнем углу с отступом 16px.
    • Фокус-ловушка обязательна, Esc закрывает, при закрытии фокус возвращается на триггер.
    • На ширине < 768px модалку заменяем нижним Sheet.

    7.5 Бейджи и статусы

    Пилюля: радиус 9999px, паддинг 3px 9px, шрифт 10–11px/700, letter-spacing: 0.1em, uppercase. Цветовая схема: текст = акцент, фон = его dim (10–12%), граница = его border (22%). Статус — всегда цвет плюс текст, цветом одним смысл не передаём.

    7.6 Тултип

    Фон #191B24, граница rgba(255,255,255,0.10), радиус 8px, паддинг 6px 12px, шрифт 14px/400 (никакого uppercase), задержка появления 200 ms, отступ от триггера 6px, авто-flip как у списков.

    7.7 Таблицы

    Шапка 12px/600 uppercase #9098b8, строки 40px, разделитель 1px rgba(255,255,255,0.06), hover строки rgba(255,255,255,0.03). Числа и ID — JetBrains Mono, выравнивание по правому краю, табличные цифры. На < 768px таблица превращается в список карточек «лейбл → значение».

    7.8 Скроллбар

    Ширина/высота 4px, трек прозрачный, ползунок rgba(255,255,255,0.10) → hover rgba(255,255,255,0.18), радиус 9999px.

    8. Иконки и медиа

    • Иконочный набор — линейный, обводка 1.5–2px (стиль Lucide). Размеры: 14 / 16 / 20 / 24px, наследуют currentColor.
    • Иконка внутри кнопки — 16px, gap до текста 8px. Кнопка-иконка обязана иметь aria-label и тултип.
    • Превью и медиа — с фиксированным соотношением (1:1, 4:3, 16:9), object-fit: cover, радиус 12px, скелетон-плейсхолдер #242632 до загрузки.
    • Изображения ниже первого экрана — loading="lazy"; у всех есть alt.
    • Видео: playsInline, muted для автоплея, постер обязателен.
    • Медиа не шире контейнера: img, video, svg, canvas, iframe { max-width: 100%; display: block; }.

    9. Мобильная версия (сводные правила)

    9.1 Брейкпоинт и переключение паттернов

    • Граница мобайл/десктоп — 768px (md). Всё, что ниже 768px, считаем мобильным/планшетным портретом.
    • Ниже 768px: нижняя навигация, Sheet вместо Dialog, таблицы → карточки, выпадающие списки прижимаются к краям экрана.
    • Проверяем три точки: 375px (компактный телефон), 768px (планшет/граница), 1440px (десктоп).

    9.2 Нижняя навигация

    • Высота: 60px + env(safe-area-inset-bottom).
    • position: fixed; bottom: 0; left: 0; right: 0; z-index: 100.
    • Фон: rgba(19,20,27,0.95) + backdrop-filter: blur(20px), верхняя граница rgba(255,255,255,0.06).
    • Максимум 5 пунктов. Если пунктов больше — последний пункт «More» с выпадающим меню.
    • Пункт: иконка 20px + подпись 11px/500, gap 4px, цвет #9FA5BC, активный — Volt #C8FF00.
    • Тач-зона каждого пункта: не менее 44×44px.
    • Контент страницы получает нижний паддинг: padding-bottom: calc(60px + env(safe-area-inset-bottom)).

    9.3 Модальные окна на мобиле

    • На ширине < 768px Dialog заменяется нижним Sheet.
    • Sheet: вход снизу, высота до 88svh, радиус верхних углов 26px, паддинг 24px.
    • Pull-индикатор сверху: 36px × 5px, цвет rgba(255,255,255,0.15), отступ сверху 8px.
    • Закрытие: свайп вниз, кнопка закрытия, клик по оверлею, Esc.

    9.4 Выпадающие списки на мобиле

    • Список не «плавает» по центру экрана — он прижимается к краям с полями 8px.
    • Максимальная ширина: calc(100vw - 16px).
    • Максимальная высота: 384px, дальше внутренний скролл.
    • Авто-flip: если снизу не хватает места — открывается вверх.

    9.5 Таблицы → карточки

    • На < 768px таблица скрывается, данные выводятся списком карточек.
    • Карточка: радиус 12px, фон #1E2029, паддинг 16px, gap между «лейбл → значение» 12px.
    • Каждая строка внутри карточки: лейбл 12px/500 #9FA5BC, значение 14px/400 #EBEEF9.
    • Числа и ID по-прежнему JetBrains Mono, выровнены по правому краю внутри строки.

    9.6 Типографика и поля на мобиле

    • Все input/select/textarea — минимум 16px, иначе iOS Safari будет зумить при фокусе.
    • Заголовки h1: clamp(32px, 6vw, 60px) — на 375px это 32px.
    • Основной текст body остаётся 15px, но ширина строки ≤ 48ch (не 68ch).
    • Кнопки в мобильных формах: высота 48px, ширина 100% контейнера, радиус 9999px.

    9.7 Тач-таргеты и safe-area

    • Минимальная зона нажатия: 44×44px. Если визуальный элемент меньше — padding увеличиваем до 44px.
    • Учитываем env(safe-area-inset-*) для iPhone с Dynamic Island и нижней полосой.
    • Горизонтальный скролл запрещён: overflow-x: clip на html/body.
    • Вертикальный скролл никогда не блокируем overflow: hidden на body.

    9.8 Тосты на мобиле

    • Позиция: верхний центр или верхний правый угол, не нижний (чтобы не перекрывать нижнюю навигацию).
    • Ширина: calc(100vw - 32px), max-width 400px.
    • Отступ сверху: calc(16px + env(safe-area-inset-top)).

    9.9 Мобильный чек-лист

    1. Нет горизонтального скролла на 375px.
    2. Все интерактивные элементы ≥ 44px.
    3. Поля ввода ≥ 16px.
    4. Dialog заменён на Sheet < 768px.
    5. Таблицы превращены в карточки < 768px.
    6. Нижняя навигация не перекрывает контент (есть нижний паддинг).
    7. Safe-area инсеты учтены.

    10. Навигация

    • Шапка 64px, sticky, фон rgba(19,20,27,0.80) + backdrop-filter: blur(20px), нижняя граница rgba(255,255,255,0.06), z-index: 40.
    • На < 768px: нижняя навигация 60px, z-index: 100, максимум 5 пунктов, иконка 20px + подпись 11px, активный пункт — Volt. Контент страницы получает нижний паддинг calc(60px + env(safe-area-inset-bottom)).
    • Табов на экране ≤ 5; больше — выпадающий список.
    • Активный пункт — цвет Volt и подчёркивание 2px, а не жирный фон.
    • Хлебные крошки только глубже 2 уровня, разделитель «/», последний элемент не ссылка.

    10. Доступность

    • Все интерактивные элементы достигаются с клавиатуры, порядок фокуса = порядок чтения.
    • Фокус-кольцо не убираем никогда: outline: none допустимо только вместе с box-shadow: 0 0 0 2px #C8FF00 (offset 2px от фона).
    • Контраст: обычный текст ≥ 4.5:1, крупный ≥ 3:1. Разрешённые пары: #EBEEF9 на #13141B/#1E2029, #9FA5BC на #13141B, #0a1100 на #C8FF00. Запрещено: #5c6280 как основной текст, белый на Volt/Lime.
    • Минимальная зона нажатия на тач-устройствах — 44×44px.
    • Каждое поле имеет <label> (визуальный или sr-only), ошибки связаны через aria-describedby.
    • Цвет — не единственный носитель смысла.

    11. Форматы, состояния, тексты

    • Язык интерфейса — английский, Sentence case для заголовков и кнопок (не Title Case, не CAPS; CAPS только для мини-бейджей).
    • Кнопка — глагол действия: «Generate», «Save changes». «OK/Submit» не используем.
    • Числа и деньги — через Intl.NumberFormat с локалью пользователя, валюта не хардкодится. Даты: относительные («2 hours ago») в лентах, MMM D, YYYY в деталях, полный timestamp — в title.
    • Длинные ID — mono, обрезка посередине, копирование по клику.
    • У каждого экрана с данными четыре обязательных состояния: loading (скелетон) → empty → error → content.
      • Скелетон повторяет геометрию контента, фон #242632, пульсация 1.5 s.
      • Empty: иконка 32px, заголовок 16px/600, строка пояснения 14px #9FA5BC, один CTA.
      • Error: короткий заголовок, человеческая причина, кнопка «Try again», технический код — 12px mono #5c6280.
    • Кнопка в процессе: спиннер 16px внутри кнопки, ширина не прыгает, кнопка disabled.
    • Тосты: правый нижний угол (на мобиле — верх), ширина до 400px, автоскрытие 5 s, ошибки — без автоскрытия.

    12. Чек-лист перед мержем UI

    1. Нет центрирующих max-width-контейнеров и 100vh; нет хардкод-цветов вне палитры.
    2. Кнопки — пилюли; на экране один primary-CTA.
    3. Любой выбор из набора — выпадающий список; он открывается от триггера, не перекрывает его, авто-flip вверх при нехватке места.
    4. Тач-таргеты ≥ 44px, шрифт полей на мобиле ≥ 16px, учтены safe-area.
    5. Есть loading / empty / error, фокус-кольцо, aria-label у иконочных кнопок.
    6. Проверено на 375 / 768 / 1440px и при prefers-reduced-motion: reduce.

    13. Чего не делать

    • Светлая тема, серые «материальные» тени, прямоугольные кнопки.
    • Второй акцентный цвет рядом с Volt в одном блоке (Volt + Sky только в градиенте).
    • Белый текст на Volt/Lime, серый #5c6280 как основной текст.
    • Радио-группы и нативные <select> вместо выпадающих списков.
    • Модалка на мобиле вместо нижнего Sheet, оверлей внутри секции без портала.
    • Uppercase и трекинг в обычных подписях и кнопках (это только для мини-бейджей).
    • Анимация width/height/top/left, длительность > 300 ms в интерфейсных переходах.
