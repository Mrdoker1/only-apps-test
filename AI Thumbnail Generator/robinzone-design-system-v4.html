Robinzone
Design System · v1.4 · ревизия документа v4

«Charged»

Тёмная, высококонтрастная система с единственным акцентом Volt. Один UI-шрифт, pill-кнопки, full-bleed раскладка, mobile-first. Все значения ниже — источник истины из src/index.css и tailwind.config.ts. Ревизия v4 закрывает пробелы v3: каркас приложения, оверлеи, формы, состояния, шкалы, доступность, микрокопирайт и процесс изменений.

Принципы

Четыре правила, которые нельзя нарушать.

ТокеныВ компонентах — только семантические токены (bg-background, text-foreground, bg-primary). Никаких text-white, bg-black, bg-[#hex].
Full-bleedКорень любой страницы/секции — PageContainer или .page-shell. Никаких mx-auto max-w-* и Tailwind .container.
Mobile-firstБазовые стили — под мобильный, вверх через sm:/md:/lg:. Тач-таргеты ≥44px. Учитывать safe-area.
100vhЗапрещён. Только min(100dvh, var(--vvh, 100dvh)) — утилиты .h-screen-safe, .min-h-screen-safe.

Селекторы параметров

Chip-строка Creation Studio: пропорции, разрешение, продолжительность, количество медиа. Всё строится из JSON-схемы модели — источник истины: src/components/composer/ModelParamsChips.tsx и src/components/creation-studio/paramsBarPrimary.ts.

Анатомия chip-строки

Контейнер: rounded-2xl border-white/[0.06] bg-black/30 p-1, gap 6px, высота бара ≥60px (desktop) / 44px (mobile). Максимум 5 первичных чипов — остальное уезжает в Advanced. Порядок фиксирован массивом PRIMARY_FIELD_ORDER.

Пропорции (aspect_ratio)

Enum-поповер: сетка пилюль с миниатюрой рамки, вычисленной из значения (MAX=16px по большей стороне). Порядок канонический: 16:9 · 9:16 · 1:1 · 4:3 · 3:4 · 21:9, auto всегда последний.

Лейбл в баре: чистое 16:9 для явных значений и Ratio: Auto для авто — см. formatChipValue().

Разрешение (resolution)

Тот же enum-поповер без иконки. Порядок: 480p · 720p · 1080p · 0.5K · 1K · 2K · 4K · 8K. Короткие коды апперкейсятся (1k → 1K), «p»-коды остаются в нижнем регистре.

Продолжительность (duration / duration_seconds)

Enum из схемы, либо синтезируется из minimum/maximum, если диапазон ≤ 20 значений. Сортировка числовая по возрастанию. 0 → «Original», auto → «Auto» и всегда в конце. Иконка — Clock.

Количество медиа (num_images)

Не enum, а stepper-поповер: minimum/maximum из схемы (дефолт 1…4). Кнопки 32×32, значение — tabular-nums. Лейбл в баре: N img с иконкой Image.

Доступность

FocusЕдиное кольцо для всего интерфейса: outline:none; box-shadow:0 0 0 2px hsl(var(--background)),0 0 0 4px hsl(var(--ring)/.7). Убирать фокус без замены запрещено. Только :focus-visible, не :focus.
КонтрастТекст ≥4.5:1, крупный ≥3:1. t3 (#5C6280) — только для декоративных подписей, не для смысла. Volt используется как фон только с тёмным --volt-txt; Volt-текст на светлом фоне запрещён.
КлавиатураВсе интерактивные элементы достижимы Tab. Поповеры и меню: ↑/↓ — перемещение, Enter — выбор, Esc — закрытие с возвратом фокуса. Focus trap только в Dialog/Sheet.
ARIAЧипы — role="radio" в role="radiogroup" с aria-checked; степпер — role="spinbutton" с aria-valuenow/min/max; switch — role="switch"; прогресс генерации — aria-live="polite".
Motionprefers-reduced-motion: reduce отключает transform-анимации, shimmer, marquee, автоплей каруселей; переходы схлопываются до 0.001ms, opacity-переходы допустимы.
ТачМинимум 44×44px. Если визуально элемент меньше — зона расширяется псевдоэлементом, а не размером иконки.
СемантикаОдин h1 на страницу, порядок заголовков не пропускается. Кнопка — button, ссылка — a. Все изображения имеют alt; декоративные — alt="".

Расхождения, процесс, версии

Известные расхождения кода и документа

РасхождениеРешение
--plasma в CSS и plasma в Tailwind заданы независимоисточник истины — CSS-переменная; Tailwind-значение синхронизировать
--gradient-hero, --glow-brand есть в CSS, но не выведены в Tailwindиспользовать только через утилиты, в компонентах не хардкодить
celebration-цвет не описан в палитреограничить одним сценарием (успешная оплата) либо удалить
.glow-plasma фактически содержит Sky-значенияпереименовать в .glow-sky или исправить значения
В boxShadow сосуществуют ключи sky и plasmaоставить один набор имён

Как менять систему

Новый токенСначала src/index.css, затем tailwind.config.ts, затем этот документ. Токен без применения хотя бы в двух местах не добавляется.
ДепрекейтКласс помечается в разделе расхождений, живёт минимум один релиз, затем удаляется вместе с использованиями в одном PR.
One-offРазовое отступление допустимо, если оно записано сюда с причиной и сроком. Незадокументированный one-off — баг.
ВерсионированиеВерсия дизайн-системы (v1.4 «Charged») и ревизия документа (v4) — разные числа. Ревизия растёт при любом изменении документа, версия — только при смене визуального языка.

Чеклист ревью UI-изменения

1Только семантические токены, нет text-white / bg-[#hex].
2Корень — PageContainer / .page-shell; нет 100vh и mx-auto max-w-*.
3Есть все четыре состояния: loading, empty, error, ready (и gated, если тратятся кредиты).
4Проверено на 360px, тач-таргеты ≥44px, safe-area учтена.
5Клавиатура и focus-visible работают; Esc закрывает оверлей.
