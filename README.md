# Robinzone — Thumbnail Generator

Вёрстка двух макетов из Figma ([Web](https://www.figma.com/design/pwU8Di7ndjFhiBNNjz2wzP/Onlyapps?node-id=14-2) и
[Mobile](https://www.figma.com/design/pwU8Di7ndjFhiBNNjz2wzP/Onlyapps?node-id=14-331)) как одна адаптивная
интерактивная страница.

**Демо:** https://mrdoker1.github.io/only-apps-test/

## Стек

React 19 + TypeScript + Vite, стили — обычный CSS с токенами в `src/styles/tokens.css`.
Брейкпоинты: две колонки рабочей области помещаются от `1280px`, ниже они складываются в
одну колонку с ограничением ширины; компактная мобильная типографика включается с `1024px`,
а короткие подписи — с `600px`.

## Разработка

```bash
npm install
npm run dev      # дев-сервер
npm run build    # прод-сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Структура

```
src/
  components/     # Header, Hero, GeneratorCard, PreviewCard, TrustedBy, Showcase, Popover
  hooks/          # useReveal — scroll-reveal через IntersectionObserver
  styles/         # tokens.css + global.css (примитивы: .eyebrow, .btn-lime, motion, focus)
  assets/         # экспортированные из Figma картинки и иконки
```

## Интерактив

- **Табы режимов** — «From prompt» переключает на textarea, «From video» и «From image» на зону
  загрузки файла с превью имени выбранного файла.
- **Параметры** (Style, Aspect ratio, Number of variants) — поповеры по правилам дизайн-системы:
  портал в `body`, открытие от триггера с отступом 8px, авто-flip вверх при нехватке места,
  триггер никогда не перекрывается, закрытие по Esc / клику вне / скроллу, возврат фокуса на триггер,
  стрелки вверх-вниз для навигации по опциям.
- **Aspect ratio** — сетка пилюль с мини-рамкой пропорции (16px по большей стороне), канонический
  порядок из дизайн-системы, `Auto` всегда последний.
- **Number of variants** — stepper-поповер, на границах диапазона кнопка гасится, а не исчезает.
- **Generate Thumbnails** — мок-генерация: кнопка блокируется, показывает спиннер и пульсирующее
  свечение, в превью появляются скелетоны, затем результаты в количестве выбранных вариантов.
- **Превью** — миниатюры выбираются кликом, выделение переезжает на выбранную.
- **Меню в шапке** — «Image» и «Video» открывают выпадающие списки.

## Анимации

- **Заголовок** — «Powered by AI» набирается посимвольно с поворотом по оси X.
- **Рукописный текст** — «Create Without Limits» инлайнится как SVG, и каждый штрих проявляется
  wipe-маской по своему bounding box в порядке настоящего письма: «Create», затем W, «ithout»,
  точка над i, L, «imits», точки и в конце подчёркивание. Стартует, когда заголовок дописан.
- **Появление карточек** — генератор выезжает слева, превью справа, с лёгким масштабом.
- **Пилюля активного таба** переезжает между табами: позиция и ширина считаются от реальной
  кнопки, поэтому она скользит, а не перерисовывается на месте.
- **Счётчик результатов** отсчитывает вверх после каждой генерации.
- **Параллакс от мыши** — лампочка и фоновые свечения смещаются на своей глубине.
- **Фон живёт сам** — световая полоса медленно дрейфует и дышит, поверх всего лежит зерно,
  которое убирает бандинг на больших мягких градиентах.
- **Контур карточки генератора** — по лаймовой рамке бежит блик: conic-gradient, обрезанный
  маской до кольца в 2px, с вращением угла через `@property`.
- **Лампочка** — пульсирующее радиальное свечение, лёгкое изменение яркости самой картинки
  и лаймовые частицы, всплывающие вверх.
- **Scroll reveal** — блоки выезжают `fade-up` 500ms `cubic-bezier(.16,1,.3,1)`.
- **Ховеры** — CTA `translateY(-1px)` + `brightness(1.1)`, active `scale(.97)`; карточки showcase
  приподнимаются с ken-burns-зумом фонового кадра; миниатюры превью зумятся; логотипы приглушаются,
  кроме наведённого. Иконки табов инлайнятся, чтобы краситься от `currentColor`, а не
  от зашитого при экспорте цвета. Иконки параметров — из набора Lucide, как требует
  дизайн-система (линейные, обводка 1.75, `currentColor`), вместо разнородных экспортов.
- **Свечение от курсора** — на карточке превью и карточках showcase контур подсвечивается
  радиальным градиентом, который следует за мышью (как MagicCard в MovieGuesser, но на CSS-
  переменных без motion-библиотеки: `--glow-x` / `--glow-y` пишутся в rAF, градиент обрезается
  маской до контура в 1px).
- **Поповеры** — fade + zoom 95→100% за 150ms со сдвигом 8px со стороны, противоположной открытию.

Всё гасится при `prefers-reduced-motion: reduce`.

## Соответствие дизайн-системе

Визуал взят из макета, а поведение — из `robinzone-design-spec-v2` / `robinzone-design-system-v4`:
токены движения, правила поповеров, фокус-кольцо 2px Volt с offset 2px, скроллбар 4px,
`overflow-x: clip` вместо `overflow: hidden`, тач-таргеты ≥44px на `pointer: coarse`,
состояния loading для генерации.

Где макет и дизайн-система расходятся, приоритет у макета — например, поверхность карточки
в макете `#13141B`, а в спеке `#1E2029`; заголовки в макете uppercase с трекингом, что спека
не рекомендует для обычных подписей.

## Деплой

Пуш в `main` запускает `.github/workflows/deploy.yml`, который собирает проект и публикует его
на GitHub Pages. `base` в `vite.config.ts` завязан на имя репозитория — при переименовании поправить.

## Отличия от макетов

- Секция «Viral Videos. Perfect Images.» в мобильном макете не нарисована. Она сохранена
  и на мобильных, карточки складываются в колонку.
- В мобильном макете нет навигационного меню — в шапке остаются только логотип и «Sign In».
